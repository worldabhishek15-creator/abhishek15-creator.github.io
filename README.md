# Abhishek Kumar | SOC Analyst (L1) Portfolio

Personal portfolio website: SIEM monitoring, threat detection and incident response projects (Wazuh, Splunk, Sysmon, MITRE ATT&CK).

Built with plain HTML, CSS and JavaScript. No build step, no dependencies.

## Files

```
index.html                    # whole website (HTML + CSS + JS)
Abhishek_Kumar_Resume.pdf     # add your CV here (used by the Download Resume button)
README.md
```

## Deploy on GitHub Pages

1. Create a new public repository named `abhishek15-creator.github.io` (user site) or any name, e.g. `portfolio`.
2. Upload `index.html`, `README.md` and your resume PDF (rename it to `Abhishek_Kumar_Resume.pdf`).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then Save.
5. Wait 1-2 minutes. Your site will be live at:
   - `https://abhishek15-creator.github.io/` (if the repo is named `abhishek15-creator.github.io`)
   - `https://abhishek15-creator.github.io/portfolio/` (if the repo is named `portfolio`)

## Customise

- Project GitHub links: search for `github.com/abhishek15-creator` in `index.html` and point each project button to its own repo.
- Add screenshots of your Wazuh/Splunk dashboards inside the project tabs using `<img src="images/your-shot.png" alt="...">`.
- Colours: edit the CSS variables at the top of the `<style>` block (`--accent`, `--accent2`).
